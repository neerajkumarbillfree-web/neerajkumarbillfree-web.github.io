🎤 Mic fix — step by step (Android)

Your phone mic is fine — the browser/app permission for this page is blocked.

  1. Test first: tap Test my mic below. If a popup appears, tap Allow.
  2. No popup (already blocked): Settings → Apps → Chrome (or Muse app) → Permissions → Microphone → Allow. Then reload.
  3. In Chrome: ⋮ menu → Settings → Site settings → Microphone — remove this site from Blocked.
  4. Google app: Settings → Apps → Google → Permissions → Microphone → Allow (Android voice uses Google's speech service).
  5. Close other apps using the mic (call, camera, recorder), then retry.

Always works: tap the text box and use the 🎤 key on your keyboard (Gboard voice typing), then Send.
